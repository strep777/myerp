# Lager 仓储 · UI/UX 设计规范

版本：1.1  
风格：macOS 风格 · 明亮 · 克制 · 新手友好  
技术：React 18 + Vite + TypeScript + Tailwind CSS 3.4 + shadcn/ui 风格组件（Radix）+ lucide-react  
关联：[PRD](01-product-requirements.md)、[API](04-api-spec.md)

## 1. 设计原则

1. **一眼看懂**：每页只有一个主任务；标题说清“这是什么”，按钮说清“会发生什么”。
2. **少即是多**：默认只显示必要字段；高级筛选收进“筛选”区；不堆参数。
3. **可恢复**：危险操作二次确认；表单失败保留输入；空状态给出下一步。
4. **一致**：同一动作在同一位置、同一文案、同一颜色；状态色全局统一。
5. **macOS 质感**：系统字体、毛玻璃侧栏、柔和阴影、克制的蓝、细腻的 150–220ms 动效；不模仿拟物。
6. **无障碍**：键盘可达、焦点可见、对比度 AA、不仅靠颜色传达状态。

## 2. 设计令牌

### 2.1 颜色

```css
:root {
  --background: 0 0% 96%;          /* #F5F5F7 页面底 */
  --foreground: 240 6% 10%;        /* #1D1D1F 主文本 */
  --card: 0 0% 100%;               /* #FFFFFF 卡片 */
  --card-foreground: 240 6% 10%;
  --muted: 240 5% 94%;             /* #EFEFF2 次级底 */
  --muted-foreground: 240 4% 44%;  /* #6E6E73 次文本 */
  --border: 240 6% 88%;            /* #E3E3E8 描边 */
  --input: 240 6% 88%;
  --ring: 211 100% 50%;            /* #007AFF 焦点 */
  --primary: 211 100% 50%;         /* #007AFF macOS 蓝 */
  --primary-foreground: 0 0% 100%;
  --secondary: 240 5% 94%;
  --secondary-foreground: 240 6% 10%;
  --accent: 211 100% 96%;          /* #EAF4FF 悬浮底 */
  --accent-foreground: 211 100% 36%;
  --destructive: 4 100% 59%;       /* #FF3B30 */
  --destructive-foreground: 0 0% 100%;
  --success: 135 59% 49%;          /* #34C759 */
  --warning: 36 100% 52%;          /* #FF9F0A */
  --info: 211 100% 50%;
  --radius: 10px;
}
```

| 用途 | 值 |
|---|---|
| 页面背景 | `#F5F5F7` |
| 卡片 | `#FFFFFF`，边框 `rgba(0,0,0,0.06)`，阴影 `0 1px 2px rgba(0,0,0,0.04)` |
| 侧栏 | `rgba(255,255,255,0.72)` + `backdrop-blur(20px)`，右侧 1px 分隔 |
| 主文本 | `#1D1D1F` |
| 次文本 | `#6E6E73` |
| 主色 | `#007AFF`，hover `#0071E3`，active `#0062C4` |
| 成功 | `#34C759`（浅底 `#EAF9EE`） |
| 警告 | `#FF9F0A`（浅底 `#FFF6E5`） |
| 危险 | `#FF3B30`（浅底 `#FFEDEC`） |
| 分割线 | `rgba(0,0,0,0.08)` |

规则：
- 主按钮每屏最多 1 个；次按钮白底描边；危险按钮仅确认弹窗内使用红色。
- 大面积不使用纯黑；正文不用纯灰过浅（对比度 ≥ 4.5:1）。
- 状态不只靠颜色：徽章同时有文字。

### 2.2 字体

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
  "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
font-feature-settings: "tnum" 1, "cv11" 1;
```

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 24/32 | 650 | 页面 h1 |
| 区块标题 | 17/24 | 600 | 卡片标题 |
| 正文 | 14/22 | 400 | 表格、表单 |
| 辅助 | 13/20 | 400 | 说明、时间 |
| 徽章 | 12/18 | 500 | 状态 |
| KPI 数字 | 30/36 | 650 | 工作台 |

数字使用 `font-variant-numeric: tabular-nums`；金额、数量右对齐。

### 2.3 间距与圆角

- 间距基数 4px；常用 8/12/16/24/32。
- 页面内边距：桌面 32px，平板 24px，手机 16px。
- 卡片圆角 12px；按钮/输入 8px；弹窗 14px；徽章 999px。
- 内容最大宽度 1440px，居中。
- 表格行高 48px；表头 40px。

### 2.4 阴影与动效

```css
--shadow-sm: 0 1px 2px rgba(0,0,0,.04);
--shadow-md: 0 4px 16px rgba(0,0,0,.06);
--shadow-lg: 0 16px 48px rgba(0,0,0,.14);
--ease: cubic-bezier(.2,.8,.2,1);
```

- 悬浮：150ms；弹窗进出：200ms；侧栏展开：220ms。
- 只动 `transform/opacity`；`prefers-reduced-motion` 时关闭。
- 不使用弹跳、旋转等夸张动效。

## 3. 布局

```text
┌──────────────────────────────────────────────────────────────┐
│ Sidebar 240px        │ Topbar 56px                          │
│ ┌──────────────────┐ │ ┌──────────────────────────────────┐ │
│ │ ● ● ●  Lager 仓储 │ │ │ 面包屑       搜索   帮助  用户 ▾ │ │
│ │                  │ │ └──────────────────────────────────┘ │
│ │ 工作台            │ │                                      │
│ │ 库存              │ │  PageHeader                          │
│ │ 入库 / 出库       │ │  ┌────────────────────────────────┐  │
│ │ 调拨 / 盘点       │ │  │ Content                        │  │
│ │ 报表              │ │  │                                │  │
│ │ 基础资料          │ │  └────────────────────────────────┘  │
│ │ 系统              │ │                                      │
│ │                  │ │                                      │
│ │ 用户卡 / 版本     │ │                                      │
│ └──────────────────┘ │                                      │
└──────────────────────────────────────────────────────────────┘
```

- 侧栏固定，毛玻璃；分组标题 11px 大写灰色字距 0.06em。
- 当前项：浅蓝底 + 蓝色图标/文字 + 左侧 2px 蓝条（或圆角胶囊底）。使用胶囊底，不用左侧条，更贴近 macOS。
- 侧栏可折叠为 72px（仅图标，tooltip）；状态存 localStorage。
- Topbar：左侧移动端菜单按钮 + 面包屑；右侧全局搜索（v1 可隐藏）、帮助（打开快捷键/说明弹窗）、用户菜单。
- 内容区滚动，侧栏与 Topbar 固定。
- 手机：侧栏变抽屉；Topbar 显示页面标题；表格变卡片列表；底部不放导航，保持内容优先。

## 4. 基础组件（shadcn 风格）

| 组件 | 规范 |
|---|---|
| Button | 36px 高（sm 32，lg 40）；primary/secondary/ghost/destructive；loading 时 spinner + 禁用；图标 16px |
| Input | 36px 高；前后缀图标；错误时红边框 + 下方 12px 文案；禁用态降低对比 |
| Select | Radix Select；触发器同 Input；选项 36px 高，选中打勾 |
| Combobox | Popover + 搜索输入 + 列表；用于商品/仓库/供应商选择；键盘上下/回车 |
| Dialog | 居中，最大宽 520px；标题 17px；底部右对齐按钮；Esc/遮罩关闭（表单有未保存内容时二次确认） |
| Sheet | 右侧滑出 480px，用于快速查看/编辑；手机全屏 |
| DropdownMenu | 行操作：查看/编辑/删除；危险项红色分隔 |
| Tabs | 分段控件样式（浅灰底胶囊），用于库存余额/流水、供应商/客户 |
| Badge | 状态徽章；圆角 999；浅底深字；12px |
| Table | 表头浅灰、粘性；行 hover `#FAFAFC`；无竖线；数字右对齐；操作列固定右侧 |
| Pagination | 「共 N 条」+ 上一页/下一页 + 页码；每页 20/50 |
| Toast | 右下角，macOS 通知质感；成功/错误/信息；3–5 秒自动消失；可手动关闭 |
| EmptyState | 线性图标 + 一句说明 + 主操作；不写“暂无数据”四个字了事 |
| ConfirmDialog | 标题、影响说明、取消/确认；危险操作确认按钮红色；确认时 loading |
| Skeleton | 列表/卡片骨架，避免白屏跳动 |
| Tooltip | 仅图标按钮、截断文本、专业名词 |
| StatusBadge | 统一映射（见 5.2） |

图标统一 lucide-react，线宽 1.75，尺寸 16/18/20；不混用其他图标库。

## 6. 页面设计

### 6.1 登录 `/login`

- 全屏柔和渐变（`#F5F5F7 → #EAF4FF`），右上/左下两团低饱和蓝色光晕，毛玻璃居中药盒 400px。
- 品牌：蓝色圆角方块内白色 `Boxes` 图标 + 「Lager 仓储」；副标题「简单、可靠的仓库管理」。
- 表单：用户名、密码（可切换可见）、登录按钮全宽；错误在表单顶部红色提示。
- 底部小字：版本号；不展示默认密码（安全）。
- 登录成功进入工作台或 `redirect`；已登录访问 `/login` 自动跳转。
- 移动端：卡片占满宽度减 32px，无光晕。

### 6.2 工作台 `/`

- 顶部问候：「晚上好，系统管理员」+ 日期；右侧「新建入库」主按钮（有权限时）。
- KPI 四卡：库存总量、库存总值、低库存商品、待处理草稿。每卡：图标、标签、数字、辅助说明（如“共 42 个 SKU”）。数字 count-up 150ms（尊重 reduced motion）。
- 中部 2:1：左「近 7 天出入库趋势」SVG 双柱图（入蓝出灰），右上切换 7/30 天；右「低库存」列表（商品、仓库、现有/安全库存），底部「查看全部」。
- 下部「最近单据」表：类型、单号、仓库、数量、状态、时间；默认 5 条；行点击进详情。
- 若 `must_change_password=true`，顶部显示「你仍在使用初始密码，请尽快修改」+ 去修改；可关闭，不阻断。
- 空状态：无数据时图表区显示「完成第一笔入库后，这里会出现趋势」+ 去入库按钮。
- 新手引导：首次登录且无数据，顶部一条可关闭提示：「从商品和仓库开始，或直接创建入库单」；不强制。

### 6.3 商品 `/products`

- PageHeader：标题「商品」、说明「统一管理商品档案与全部库存」、右侧「新建商品」。
- 工具条：搜索（SKU/名称/条码）、分类下拉、状态分段（全部/启用/停用）、重置。
- 表：SKU、名称、分类、单位、规格、安全库存、参考成本、状态、操作。
- 新建/编辑用 Dialog（两列表单）：必填 SKU、名称；单位默认“件”；分类自由文本 + 已有分类建议（datalist）；参考成本、参考售价、安全库存、备注。
- 停用确认：「停用后不能用于新单据，历史记录保留」。有库存时提示库存数量。
- 行内有库存时显示「清空库存」图标：确认后把该商品全部仓库余额清零，写调整流水，商品保留。
- 删除商品会连同库存余额与库存流水一起删除；被历史单据引用时不能删除，提示改为停用。
- 列表额外显示当前总库存与低库存标记（按所有仓库合计）。
- 空状态：「还没有商品」+ 新建；搜索无结果：「没有匹配的商品」+ 清除筛选。
- 批量操作 v1 不做。

### 6.4 仓库 `/warehouses`

- 卡片网格（每行 3/2/1）而非表格：仓库名 + code、位置、负责人、备注、库存 SKU 数、状态、编辑/删除。
- 新建/编辑 Dialog；停用前若有库存，后端拒绝，前端展示具体余额条数；无库存且无引用可删除。
- 空状态引导新建第一个仓库。

### 6.5 供应商/客户 `/partners`

- Tabs「供应商」「客户」；同一表格组件复用。
- 列：编码、名称、联系人、电话、邮箱、状态、操作。
- 新建/编辑 Dialog：编码、名称必填；联系方式与备注选填。
- 搜索 + 状态筛选；停用确认；无引用可删除，被引用时提示停用。

### 6.6 库存 `/inventory`

Tabs：「库存余额」「库存流水」。

**余额**
- 工具条：仓库选择（默认全部）、搜索、分类、低库存开关、含零库存开关。
- 概览条：SKU 数、总数量、总值、低库存数（当前筛选范围）。
- 表：商品（名称+SKU）、仓库、数量、单位、平均成本、库存金额、安全库存、状态；只读，无调整操作。
- 数量低于安全库存：数字红色 + 小圆点；行不整行变红。
- 库存管理入口统一在商品页；本页只用于查看和导出/复制，不再提供「库存调整」。
- 点击行打开右侧 Sheet：商品信息 + 最近 10 条流水 + 「查看全部流水」。
- 空状态区分「没有库存」与「筛选无结果」。

**流水**
- 筛选：商品 Combobox、仓库、类型、日期范围、单号；重置。
- 表：时间、商品、仓库、类型、变动、结存、单价、来源单号、操作人、备注。
- 变动正数绿色 `+`，负数红色 `−`（同时有符号，不只靠颜色）。
- 来源单号可点击跳转单据详情（有权限时）。
- 分页 20/50；导出入口跳报表。

### 6.7 入库单 `/inbound-orders`

**列表**
- PageHeader + 「新建入库单」。
- 状态 Tabs：全部/草稿/已确认/已取消（带数量）。
- 筛选：搜索单号/供应商、仓库、日期范围。
- 表：单号、供应商、仓库、数量、金额、状态、创建人、创建时间、操作。
- 行操作：查看、编辑（草稿）、删除（草稿）、确认（草稿）。
- 确认弹窗：摘要（仓库、行数、总数量、总金额）+ 提示「确认后将增加库存且不可修改」；确认按钮 loading。

**表单 `/inbound-orders/new`、`/inbound-orders/:id/edit`**
- 页头：返回、标题「新建入库单」、右侧「保存草稿」「保存并确认」。
- 基本信息卡：供应商（可空 Combobox + 快速新建？v1 不做快速新建，提示去基础资料）、仓库（必选）、关联单号（选填）、预计到货日（选填）、备注。
- 明细卡：行编辑器。
  - 添加行按钮；商品 Combobox 搜索 SKU/名称；选中后带出单位、参考成本作为默认单价。
  - 列：商品、单位、数量、单价、金额（自动）、备注、删除。
  - 数量/单价输入右对齐；失焦格式化 2 位（数量最多 4 位）；错误行红框。
  - 同一商品重复：提示并阻止保存。
  - 底部合计：行数、总数量、总金额。
  - 至少 1 行；空行自动忽略。
- 未保存离开：确认弹窗「有未保存的修改，确定离开？」。
- 保存成功：toast + 跳详情；保存并确认：确认成功后跳详情。
- 移动端：基本信息单列；明细变卡片，每行一张。

**详情 `/inbound-orders/:id`**
- 页头：返回、单号 + 状态徽章、右侧操作（编辑/确认/删除/打印？v1 不做打印）。
- 信息卡：供应商、仓库、关联单号、预计到货日、创建人、创建时间、确认人、确认时间、备注。
- 明细表 + 合计。
- 确认/删除复用弹窗；确认后所有编辑按钮消失。
- 底部时间线：创建 → 确认（显示人与时间）。

### 6.8 出库单 `/outbound-orders`

结构与入库一致，差异：
- 客户替代供应商；无单价/金额列；明细列：商品、单位、数量、备注。
- 基本信息含关联单号、预计发货日（选填）。
- 确认弹窗提示「将扣减库存；库存不足会整单失败」。
- 若 409 库存不足：弹窗内展示不足明细表（商品、需求、可用），保留弹窗，用户可返回修改。

### 6.9 调拨单 `/transfer-orders`

- 表单顶部并排「调出仓库 → 调入仓库」，中间箭头图标；两者不能相同（前端即时校验）。
- 明细同出库（无金额）；确认弹窗提示双仓库存变化。
- 详情显示源仓/目标仓与合计。

### 6.10 盘点单 `/stocktakes`

**列表**：单号、仓库、状态、明细数、差异数、创建人、创建时间、操作。
**创建 Dialog**：仓库必选、备注；提示「将快照该仓库全部启用商品，实盘数默认等于账面」。该仓已有进行中盘点时提示先完成；无启用商品时报错。
**详情/录入**
- 页头：单号 + 状态；右侧「保存进度」「完成盘点」「取消盘点」。
- 说明条：盘点期间请勿同时出库/入库；系统以完成时点为准。
- 表：商品、单位、账面数、实盘数（Input，右对齐，默认等于账面）、差异（自动，绿盈红亏）、备注。
- 顶部汇总「共 30 项，差异 2 项，净差异 −3」。
- 单行提供「实盘=账面」快捷按钮；不做全表填充，避免误操作。
- 完成弹窗列出差异汇总（盘盈 N 项 +X，盘亏 M 项 −Y），允许零差异完成；确认后入账。
- 完成后只读，显示完成人/时间。
- 取消确认；已入账不能取消。

### 6.11 报表 `/reports`

Tabs：「库存汇总」「低库存」「库存流水」「收发存」。
- 统一筛选条：仓库、日期范围（流水/收发存）、分类、搜索。
- 库存汇总：商品、仓库、数量、平均成本、金额、占比条（可选）。
- 低库存：商品、仓库、现有、安全库存、缺口、建议补货（缺口）。
- 流水：复用库存流水表，精简列。
- 收发存：期初、入库、出库、调整、期末、期末金额；日期必填（默认本月）；表头说明口径 tooltip。
- 右上「导出 CSV」：按当前筛选导出；loading；成功 toast；浏览器下载。
- 空状态与加载骨架；报表不做图表（工作台已有趋势），保持表格高效。

### 6.12 用户管理 `/system/users`（ADMIN）

- 表：用户名、显示名、角色、状态、创建时间、操作（编辑/重置密码/停用）。
- 新建 Dialog：用户名、显示名、初始密码、角色；密码可生成随机（按钮 + 复制）。
- 编辑：显示名、角色、状态；最后一个管理员不可停用/降级（前端禁用 + 后端兜底）。
- 重置密码：输入新密码或生成；确认后提示「用户需重新登录」。
- 不能停用自己：按钮禁用并 tooltip。

### 6.13 审计日志 `/system/audit-logs`（A/M）

- 筛选：用户、动作、日期范围、关键字。
- 表：时间、用户、动作、对象、摘要、IP。
- 动作徽章颜色：LOGIN 蓝、CONFIRM 绿、DELETE/CANCEL 红、其余灰。
- 行展开显示 `detail` JSON 的格式化只读视图（可选 v1 不展开；列表摘要足够）。
- 只读，无删除。

### 6.14 AI 智能入库 `/ai`（A/M/O）

- 页头「AI 智能入库」，副标题说明“上传购买截图或粘贴商品链接，AI 提取商品、数量与金额，核对后直接入库”。
- 左侧来源卡：Tabs「截图 / 链接 / 文字」；截图区支持拖拽/点击/`Ctrl+V` 粘贴，另有“从剪贴板粘贴”按钮，显示格式与 4MB 限制；任意 tab 粘贴图片会自动切回截图。链接输入 URL；文字 textarea。补充说明可选。
- 主按钮「开始 AI 识别」，耗时提示 5–30 秒；识别中禁用重复提交。
- 右侧空态三步说明：提供来源 → 核对预览 → 确认入库。
- 预览卡：来源摘要、提供商/模型/耗时、warning 黄条、入库仓库（必选）、供应商（默认“按识别结果自动匹配或创建”）。
- 桌面：表格列商品/数量/单价/小计；移动端：卡片显示名称、SKU/规格/置信度/匹配状态，数量与单价输入，小计与删除。
- 底部「确认并立即执行入库」与主按钮；关闭后只生成草稿。
- 成功态：绿色图标、单号、数量、金额、新建商品提示；按钮「查看入库单」「再识别一单」。
- 所有 AI 输出当作文本渲染，不使用 `dangerouslySetInnerHTML`。

### 6.15 系统设置 `/system/settings`（ADMIN）

- 页头保存按钮；主体两列：左侧提供商/连接/默认提示词，右侧入库策略与使用建议。
- 提供商卡片：DeepSeek（默认，云）与 Ollama（本地）；选中态蓝色边框 + 圆点。
- 字段：服务地址、API Key（密码框 + 显示/清除，留空表示不修改）、测试连接。
- Ollama 模型：从 `GET /ai/ollama/models` 动态读取为下拉；当前标签不在列表时显示“未在列表”+ 琥珀提示；无列表时保留手填；“获取模型”按钮显式刷新，不在每次地址输入时请求。
- 测试连接结果三态：网络/服务失败（红）、连接成功但模型不存在（琥珀，列出可用模型）、连接且模型可用（绿）。
- 默认提示词 textarea 可滚动，显示字符数与版本；「恢复默认」二次确认。
- 自动确认开关，说明“关闭后只生成草稿”。
- 密钥掩码、最近更新时间；不显示明文 Key。

### 6.16 404 / 错误页

- 大号 `404` 或插画 + 「页面不存在」+ 「返回工作台」。
- 403 页面：「没有访问权限」+ 返回；不暴露资源是否存在。
- 全局 ErrorBoundary：`出了点问题` + 刷新按钮 + request_id（若可得）。

## 7. 关键交互规范

### 7.1 表单

- 标签在输入框上方，左对齐；必填星号红色；说明文字 12px 灰色。
- 校验时机：失焦 + 提交；提交时滚动到第一个错误。
- 错误文案具体：「数量必须大于 0」，不写「输入有误」。
- 数字输入：`inputMode="decimal"`；禁止科学计数法；最多 4 位小数；不允许负数（除调整数量）。
- 提交按钮 loading 时禁用整表单，防重复提交。
- 成功后：关闭弹窗/toast/刷新列表；不需要用户手动刷新。

### 7.2 删除与确认

- 删除仅草稿：红色文字按钮 → ConfirmDialog，说明不可恢复。
- 确认单据：说明库存影响与不可撤销；确认按钮用主色（非红色），因为不是破坏性操作，但不可逆。
- 取消单据：红色确认；已确认单据不显示取消。

### 7.3 表格与分页

- 默认 20 条/页；切换 50 时回到第 1 页。
- 筛选变化重置到第 1 页。
- 排序仅支持白名单（时间、单号、数量），点击表头切换升降序，带箭头。
- 空值显示 `—`，不显示 `null`。
- 长文本截断 + tooltip；单号等宽字体。
- 所有业务列表首列提供复选框；表头复选框支持全选/取消当前页与 indeterminate。
- 选择工具条仅在已选 N>0 时显示「本页已选 N / total 项」，提供“全选本页/取消全选”“复制选中”。
- 可删除的业务列表额外显示红色“清除数据”：二次确认后逐条调用 DELETE，成功项从列表消失，失败项保留并 toast 说明原因（仓库有库存、被历史单据引用、非草稿等）。**取消全选只负责取消勾选，不删除数据；清除数据与应用内勾选状态无关。**
- 可清除范围：商品（库存余额与流水一并清除）、仓库、供应商/客户、入库/出库/调拨草稿、盘点草稿。库存余额、库存流水、用户、审计日志、报表是派生/审计/只读数据，不提供删除按钮，只保留全选与复制，避免破坏账实与审计链。
- 分页、筛选、tab 切换或数据重载后清空选择；批量删除只对当前页选中项生效。

### 7.4 加载与错误

- 首屏：骨架屏；局部刷新：按钮 spinner 或表格顶部细进度条。
- 网络错误：页面级错误块 + 重试；不白屏。
- 401：跳登录并 toast「登录已过期，请重新登录」。
- 409 库存不足：表单顶部 Alert + 明细，滚动到可见。
- 500：toast 附 request_id；控制台记录。

### 7.5 键盘与快捷

- `Esc` 关闭最上层弹窗/抽屉。
- `Enter` 在搜索框提交；在表单中不自动提交（避免误操作），除 Combobox 选择。
- `Tab` 顺序自然；弹窗焦点陷阱，关闭后回到触发按钮。
- 全局 `/` 聚焦当前页搜索（若存在）；`?` 打开快捷键说明（v1 可只做 `/`）。
- 不做复杂命令面板。

### 7.6 新手指引

- 顶栏「新手指引」按钮，始终可再次打开，不依赖首次登录。
- 桌面：高亮侧栏工作台、库存、业务、AI 助手、系统设置，最后高亮按钮本身。
- 移动端：指引开始时打开非模态 280px 导航面板；每步高亮面板内目标；结束后关闭面板并回到工作台。
- 使用 Intro.js：`nextLabel=下一步`、`prevLabel=上一步`、`doneLabel=开始使用`、`skipLabel=退出`、显示进度、不显示圆点、点击遮罩不退出。
- 完成写入 `localStorage["lager_tour_completed"]="1"`；不强制、不重复弹窗。
- 样式覆盖为 macOS 风格：白底、12px 圆角、轻阴影、蓝色主按钮。

## 8. 文案规范

| 场景 | 推荐 | 避免 |
|---|---|---|
| 按钮 | 新建入库单、保存草稿、确认入库、导出 CSV | 提交、确定、执行 |
| 空状态 | 还没有商品，先创建一个吧 | 暂无数据 |
| 错误 | 库存不足：A4 复印纸可用 4 包，需要 10 包 | 操作失败 |
| 确认 | 确认后将增加库存，且不能修改 | 是否继续？ |
| 成功 | 入库单已确认 | 操作成功 |
| 权限 | 你没有权限执行此操作 | 403 |

- 使用「你」而非「您」，简洁平等；正式公告可用「您」。
- 不出现技术词（JWT、SQL、500）给终端用户；request_id 除外。
- 数量带单位；金额带 `¥` 和千分位。

## 9. 响应式

| 断点 | 布局 |
|---|---|
| ≥1280 | 侧栏 240px，内容 2–4 列 |
| 768–1279 | 侧栏折叠 72px（可展开覆盖），KPI 2×2，表格横向滚动 |
| <768 | 侧栏抽屉，Topbar 紧凑；KPI 2×2 或单列；表格转卡片；表单全屏；弹窗全屏 Sheet；AI 预览必须使用卡片，不依赖横向滚动 |

- 触控目标 ≥ 44×44px。
- 横向滚动表格时首列粘性；操作列粘性右侧。
- 不在手机端隐藏关键列（状态、数量），改为卡片字段。

## 10. 无障碍

- 所有输入有 `<label>`；图标按钮有 `aria-label` + tooltip。
- 焦点环：2px 蓝色 + 2px offset，不用 `outline: none`。
- 颜色对比：正文 ≥ 4.5:1，大字号 ≥ 3:1；状态徽章文字加深。
- 表格有 `<caption>` 或 `aria-label`；排序按钮 `aria-sort`。
- 弹窗 `role=dialog`、`aria-modal`、标题关联；焦点陷阱。
- Toast 使用 `aria-live=polite`；错误用 `role=alert`。
- 动效尊重 `prefers-reduced-motion`。
- 不自动播放声音/视频。
