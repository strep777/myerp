# Lager 仓储 · 用户手册

版本：1.1（2026-11-09）  
本手册面向仓库管理员、采购/销售内勤和日常操作人员。所有业务页面都遵循同一套交互：左侧导航进入模块，顶部筛选，表格查看数据，右上角按钮执行新建等操作。

## 1. 登录与账户

1. 打开系统地址（默认 `http://127.0.0.1:8000`）。
2. 输入用户名和密码，点击“登录”。
3. 首次使用管理员账号：`admin / Admin@12345`。登录后请立即点击右上角头像 → “修改密码”。

密码要求：8–64 位，至少包含字母和数字，不能包含用户名。修改密码后所有旧会话失效，需要重新登录。

角色说明：

| 角色 | 能做什么 |
|---|---|
| 管理员 ADMIN | 全部功能，包括用户管理 |
| 经理 MANAGER | 主数据、商品清空库存、单据、盘点、报表、审计 |
| 操作员 OPERATOR | 单据录入与确认、盘点录入，不能改主数据/调整库存 |
| 只读 VIEWER | 查看数据、导出报表，不能修改 |

## 2. 工作台

工作台展示：

- 商品数、仓库数、库存总量、库存总值
- 低库存商品数、草稿单据数、今日入库/出库
- 最近 7 天出入库趋势
- 最近 5 张单据和低库存 Top 5

点击 KPI 卡片可跳转到对应筛选页面。右上角仓库下拉可以按仓库查看。

## 3. 商品、仓库、供应商、客户

### 商品

进入“商品”，可搜索商品名/SKU，按分类、启用状态筛选。

- 新建商品：填写 SKU、名称、分类、规格、单位、条码（可选）、安全库存、参考成本、参考售价、备注。
- SKU 唯一；条码如果填写也必须唯一。
- 列表中的“库存”来自所有仓库余额合计；库存小于等于安全库存时显示低库存标记。
- 有库存商品可点行内“清空库存”图标，把该商品在全部仓库的库存清零（写库存调整流水，商品保留）。
- 删除商品会同时清除该商品在所有仓库的库存余额与库存流水；被历史单据引用时不能删除，只能停用。

### 仓库

- 仓库编码唯一；停用前该仓库库存必须为 0，且系统至少保留一个启用仓库。
- 有库存或单据引用的仓库不能删除，只能停用。

### 供应商 / 客户

- 编码唯一，名称必填，邮箱如果填写必须格式正确。
- 已被入库/出库单引用时不能删除，只能停用。

## 4. 库存余额与流水

### 库存余额

“库存 → 库存余额”是只读总览，显示每个商品在每个仓库的数量、移动平均成本、库存价值和安全库存。

- 可按商品/仓库搜索，勾选“仅低库存”或“显示零库存”。
- 库存管理统一在“商品”页面完成：有库存商品可点“清空库存”；删除商品会一并清除库存余额与库存流水。
- 本页不再提供“库存调整”入口，避免同一库存存在两个管理入口。

### 库存流水

“库存 → 库存流水”按时间倒序显示所有库存变动：

- 入库、出库、调拨入、调拨出、盘点盈亏、库存调整
- 每行包含变动数量、变动后余额、单位成本、关联单号和操作人
- 可按商品、仓库、类型、日期、关联单号筛选并导出 CSV

流水是审计依据，已生成后不可编辑或删除。

## 5. 入库单

路径：左侧“入库”。

1. 点击“新建入库单”。
2. 选择仓库（必填）、供应商（可选），填写关联单号、预计日期、备注。
3. 添加明细：选择商品，填写数量（>0）和单位成本（≥0），可逐行备注；同一商品不能重复。
4. 保存后单据为“草稿”，可继续编辑、删除。
5. 核对无误后点击“确认入库”。确认后：
   - 库存增加，写入入库流水；
   - 按移动加权平均更新该商品在该仓库的平均成本；
   - 单据变为“已确认”，不可再编辑。
6. 草稿可取消，取消后保留记录但不再参与库存。

> 入库确认是原子的：任何一行失败，整张单不会产生库存变化。

## 6. 出库单

路径：左侧“出库”。

1. 新建出库单，选择仓库和客户（可选），填写关联单号、预计日期、备注。
2. 添加商品和数量（>0），同一商品不能重复。
3. 保存草稿，核对后点击“确认出库”。
4. 系统按仓库检查全部明细库存；**任意一行不足，整单失败**，并提示缺口数量。
5. 确认成功后库存减少，写入出库流水。

出库单不记录金额，库存成本按该仓库当前移动平均成本结转。

## 7. 调拨单

路径：左侧“调拨”。

1. 新建调拨单，选择调出仓库和调入仓库（不能相同）。
2. 添加商品和数量。
3. 保存草稿并确认。
4. 系统先检查调出仓库存，任一明细不足则整单失败。
5. 确认时逐行写两条流水：调出仓 `TRANSFER_OUT`、调入仓 `TRANSFER_IN`；调入成本取调出仓当前平均成本。

## 8. 盘点

路径：左侧“盘点”。

1. 新建盘点，选择仓库。系统会快照该仓库当前全部启用商品（包括库存为 0 的商品）。
2. 同一仓库同时只能有一个“草稿/盘点中”的盘点单。
3. 在详情页逐行填写实盘数量，可搜索商品或勾选“仅看差异”；点击“保存实盘”可分批保存。
4. 全部录入后点击“完成盘点”。系统会再次核对账面数量：
   - 如果盘点期间库存发生了变化，会提示“账面已变化”，请重新加载后再处理；
   - 确认后差异写入 `STOCKTAKE_GAIN` / `STOCKTAKE_LOSS` 流水，盘点单变为“已完成”。
5. 零差异也可以完成。已完成/已取消的盘点只读。

## 9. 报表

路径：左侧“报表”，包含四个页签：

- **库存汇总**：按商品/仓库展示数量、均价、金额，可导出 CSV。
- **低库存**：低于安全库存的商品及建议补货量。
- **收发存**：按日期区间统计期初、入库、出库、调整、期末。
- **库存流水**：与库存流水页相同的明细查询，可导出。

收发存口径：入库只统计 `INBOUND + TRANSFER_IN`，出库只统计 `OUTBOUND + TRANSFER_OUT`，调整统计盘点盈亏与库存调整净额；期末 = 期初 + 入库 − 出库 + 调整。调拨在源仓计出库、目标仓计入库。

CSV 默认带 UTF-8 BOM，Excel 可直接打开；单次最多导出 50,000 行。

## 10. 用户、审计与系统信息

### 用户管理（仅管理员）

- 新建用户：用户名、显示名、初始密码、角色。
- 编辑：显示名、角色、启用/停用。
- 重置密码：设置新密码后该用户旧会话全部失效。
- 不能停用自己；系统至少保留一个启用的管理员。

### 审计日志（管理员/经理）

记录登录、退出、改密、主数据增删改、单据确认/取消/删除、盘点完成等关键动作，可按用户、动作、对象、日期和关键词筛选。

### 系统信息

展示应用版本、运行状态、时区、数据库类型、用户数、运行时长和健康检查地址。仅登录用户可查看。

### AI 智能入库（管理员/经理/操作员）

1. 左侧点“AI 助手”。
2. 选择来源：
   - **截图**：拖入、点击上传，或直接按 `Ctrl+V` 粘贴剪贴板里的订单/商品截图；也可以点击“从剪贴板粘贴”。支持 PNG、JPEG、WebP、GIF，最大 4 MB。
   - **链接**：粘贴公开商品页或订单页 URL。
   - **文字**：直接输入“买了两条 USB-C 数据线，单价 16 元”。
3. 可补充说明，例如“这是 8 月的采购，供应商是晨光”。
4. 点“开始 AI 识别”，等待 5–30 秒。
5. 核对预览：
   - 绿色点表示匹配到已有商品；橙色点表示将新建商品。
   - 修改数量、单价或商品名；可删除行或添加行。
   - 选择入库仓库；供应商可自动匹配/创建，也可手动指定。
6. 点“确认并入库”。若设置里关闭了“确认后立即执行入库”，这里只生成草稿，需要到入库单详情再确认。
7. 成功后点“查看入库单”核对单据与库存流水。

注意：AI 只负责识别，最终数量、单价和是否入库由你确认；识别结果不正确时直接修改或放弃。

### 系统设置（仅管理员）

- **提供商**：DeepSeek（云端，默认）或 Ollama（本地）。
- **服务地址**：DeepSeek 默认 `https://api.deepseek.com`；Ollama 默认 `http://127.0.0.1:11434`。Docker 中访问宿主 Ollama 用 `http://host.docker.internal:11434`。
- **模型**：DeepSeek 默认 `deepseek-flash`；Ollama 不再写死，点“获取模型”从本机 `/api/tags` 读取真实标签并在下拉中选择。当前保存的标签不在列表时显示“未在列表”，可重新选择或先 `ollama pull <模型名>`。
- **API Key**：只写不回显；留空表示不修改；勾选“清除密钥”后保存才会删除。
- **测试连接**：保存前可先测试；网络失败、连接成功但模型不存在（会列出可用模型）、连接且模型可用三种结果分别提示。
- **默认提示词**：约束 AI 的角色、输出 JSON 字段和异常处理；点“恢复默认”可恢复内置版本。
- **自动确认**：开启后“确认并入库”会立即确认单据并改库存；关闭后只建草稿。

### 新手指引与列表全选

- 顶栏“新手指引”可随时打开，按提示点“下一步”即可；移动端会自动打开导航面板。
- 所有列表表头有复选框：勾选可全选当前页；部分选中显示为横线。
- 选中后工具条显示“本页已选 N / total 项”，可取消全选或复制选中内容。
- 商品、仓库、供应商/客户、草稿单据、草稿盘点额外显示红色“清除数据”：点击后会二次确认，确认即永久删除选中记录。商品删除会连同全部库存与流水一起清除；被历史单据引用、已确认或已完成的记录不会被删除，会保留并提示原因。
- 库存余额、库存流水、用户、审计日志、报表是派生/审计/只读数据，不提供“清除数据”，只能全选和复制。需要清零某个商品的库存，请到商品页点“清空库存”。
- 翻页或筛选后会清空选择，避免误操作看不见的行。
- **停止服务**：Windows 双击 `stop.bat`，脚本只停止“8000 端口 + Lager 健康检查 + python 进程”三者同时匹配的进程；如果 8000 被 DSH、其他 Python 或别的工具占用，会拒绝停止并提示 PID，不会误杀。

## 11. 常见问题

| 现象 | 处理 |
|---|---|
| 登录后马上跳回登录页 | 检查系统时间；HTTPS 部署需 `COOKIE_SECURE=true`，HTTP 本地部署需 `false`；清除浏览器 Cookie 后重试 |
| 页面刷新 404 | 确认 `frontend/dist` 存在，后端由 FastAPI 托管；开发模式请访问 Vite 的 5173 端口 |
| 出库提示库存不足 | 查看提示中的可用数量；先入库或调整，再重新确认 |
| 盘点提示账面已变化 | 盘点期间发生了出入库；刷新详情，按最新账面重新核对实盘数 |
| 删除商品/仓库提示被引用 | 商品被历史单据引用、仓库仍有库存时不能删除；先停用或清空库存 |
| 忘记管理员密码 | 参考部署文档“重置管理员密码”章节，停止服务后用脚本重置 |
| AI 测试连接失败 | Ollama 是否启动、地址是否正确；DeepSeek Key 是否有效、服务器能否出站 |
| AI 上传图片返回 413 | 图片超过限制；先压缩到 4 MB 内；Nginx 需为 `/ai/analyze` 放行 6 MB |
| AI 识别不出商品 | 截图是否清晰、是否包含商品名/数量/价格；补充文字说明后重试 |
| 确认入库提示令牌过期 | 预览超过 30 分钟；重新识别一次 |
| 端口被占用 | 修改 `.env` 的 `APP_PORT`，或停止占用 8000 端口的程序 |
| Ollama 提示模型不存在 | 点“获取模型”重新读取本机标签；没有该模型就先 `ollama pull <模型名>`，不要手写不存在的标签 |

## 12. 数据安全建议

- 每日备份，至少保留 14 天，并定期做恢复演练。
- 不共享账号；人员离职后及时停用。
- 库存调整、盘点完成等动作前先核对业务单据。
- 生产环境使用 HTTPS，关闭 API 文档，限制数据库端口暴露。
